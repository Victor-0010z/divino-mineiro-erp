# Divino Mineiro ERP

Frontend MVP do sistema interno do restaurante Divino Mineiro.

## Executar

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

Contas de demonstração:

- `admin@divinomineiro.com.br` / `divino123`
- `gerente@divinomineiro.com.br` / `divino123`

Os dados estão simulados em memória. A camada `src/lib/services` está preparada para ser substituída pela API Spring Boot.
